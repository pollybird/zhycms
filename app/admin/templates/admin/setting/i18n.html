    总开关

    启用后，前台/后台将出现语种切换器，并按各语种翻译文件渲染界面文案。数据库内容（栏目名、文章标题等动态数据）不参与国际化，仅界面文案翻译。

    默认语种

    Accept-Language 无法匹配时，亦回落至此默认值。

    {% for code, label in locale_options %}
    {% endfor %} 至少保留一个语种；新增语种需先执行 pybabel init/compile 生成翻译。

    翻译文件维护流程

    # 提取待翻译字符串
pybabel extract -F babel.cfg -o app/translations/messages.pot app/
# 新增语种（首次）
pybabel init -i app/translations/messages.pot -d app/translations -l en
# 翻译变更后更新
pybabel update -i app/translations/messages.pot -d app/translations
# 部署前编译（生成 .mo）
pybabel compile -d app/translations
