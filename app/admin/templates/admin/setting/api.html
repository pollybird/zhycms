    访问控制

    设置后，第三方请求须携带请求头 X-API-Token: 你的Token。仅只读接口，不提供写操作。
    供小程序/H5 前端跨域调用，多个域名用英文逗号分隔，留空不允许跨域。

    缓存

    接口响应缓存时长，0 = 不缓存。内容更新后最长延迟该时长同步。
